# 📝 VibeCoding To-Do App

A beautiful, minimalist To-Do list application developed with **Flutter**. 

This project focuses on clean code architecture and a calming user experience. Originally conceptualized and built natively in Kotlin, this application was entirely rewritten in Flutter to explore cross-platform widget structures and component-based UI design. 

The interface is crafted with a specific aesthetic in mind—blending a cozy, dark academia vibe with deep crimson accents (`#8B0000`) to make everyday task management a little more mindful, allowing users to focus on the present moment and the small details.

## ✨ Features
*   **Cross-Platform Ready:** Built to run smoothly on Android, with a codebase easily adaptable for web and iOS.
*   **Mindful UI:** A custom-themed, clutter-free interface designed to reduce overwhelm and boost focus.
*   **Seamless Task Management:** Easily add, check off, and track daily goals.
*   **Material 3 Design:** Fully utilizes Flutter's latest `ThemeData` and Material 3 design guidelines.

## 🛠️ Tech Stack
*   **Framework:** Flutter
*   **Language:** Dart
*   **Architecture:** Stateless/Stateful widget separation
